## About the Project

This repository contains HTML, CSS, and JavaScript coursework and lab exercises. The portfolio homepage organizes links to interactive pages, supporting files, validation screenshots, and output examples by lab.

- **6 labs**
- **56 lab assignment HTML pages** (Labs 1–6; excludes the main portfolio page)
- **10 external CSS stylesheets**
- **8 JavaScript files**
- **32 screenshots total**: 24 validation screenshots and 8 Lab 6 output screenshots

- **Lab 5:** `bgImage.html`, `external.html`, `food.html`, `inline.html`, `internal.html`, `link.html`, `navigation.html`, `shop.html`, `table.html`, `umt.html`
- **Lab 6:** `changelight.html`, `datetimejs.html`, `disable-right-click.html`, `extjavascript.html`, `firstjs.html`, `firstjs-formatted.html`, `firstjs-6.4.html`, `form-validation.html`, `grade.html`, `guess-number.html`, `index.html`, `lab6_ExerA.html`, `multiplication-table.html`, `numeric-validation.html`

Lab 4 includes the stylesheets `style.css`, `style_ExerA.css`, and `cafe.css`. Lab 5 includes `style.css`, `food.css`, `shop.css`, and `umt.css`, along with the image assets `books.jpg` and `header-bg.jpg`. Lab 5 validation screenshots (`validation_food_html.png`, `validation_food_css.png`, `validation_shop_html.png`, and `validation_shop_css.png`) are available in the portfolio gallery.

Lab 6 includes the stylesheets `game.css`, `grade.css`, and `style.css`, along with the JavaScript files `form-validation.js`, `game.js`, `grade.js`, `guess-number.js`, `message.js`, `multiplication-table.js`, `numeric-validation.js`, and `script.js`. Its visual assets are `paper.png`, `rock.png`, and `scissors.png` for the game, plus `pic_bulboff.gif` and `pic_bulbon.gif` for the light-bulb exercise. The portfolio gallery features 8 example output screenshots for the game and grade calculator; these are not validation screenshots.

Lab 3 does not yet have a validation screenshot for `inattribute5.html`.

## Viewing the Portfolio

The portfolio is a static website and requires no build step or dependency installation.

2. Open the root-level `index.html` in a web browser to view it locally.
